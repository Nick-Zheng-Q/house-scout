# Privacy / 隐私说明

House Scout is a Dayweaver skills package, not a hosted listing database. There is no bundled telemetry, analytics endpoint, account, cookies, MCP server or automatic data upload to Dayweaver. Installing the package does not send housing records to its publisher.

Live browsing, geocoding, routing and business lookup send queries/endpoints to the provider chosen by the host/user. Do not submit private addresses, identity documents, finances or occupants’ personal details without task-specific authorization. Provider and host privacy policies apply independently. Helpers may save local request URLs, timestamps, responses and one-hour caches outside the skill; those can contain disclosed addresses. Keep them private, use per-task output/cache directories, and remove only your own task files when no longer needed.

No automatic owner contact, viewing booking, application, payment or signing. No background monitoring. GitHub issues are public: use redacted summaries, not private records or keys. The optional Dayweaver link in the GitHub README is publisher attribution, not a transfer of user data or a subscription requirement.

本项目不自带遥测或托管账号；浏览/地图查询的数据会发送给所选提供方，私人信息需具体授权。本地请求/缓存可能含地址，应保密。不要在公开issue提交私人资料；没有后台监控、自动联系或交易动作。第三方服务和宿主各自的隐私政策独立适用。
