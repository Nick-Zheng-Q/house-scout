# 居住适配、出行与周边配套

要求公共交通时先读[实际时段公交查询](transit-guide.md)：仅步行不能满足该要求。原目标日乘车行程、精确日期参考、接驳及匹配票价分别报告。

按相关司法辖区和当地术语读[市场指引](international-markets.md)，周期、现金、月票和融资口径读[成本计算](cost-comparison.md)；中国大陆渠道仍见[平台操作](platforms.md)。

对每个保留的**具体房源**补齐这些信息；只找到小区或楼盘时，周边数据可作线索，但不能替代单元户型、楼栋出入口和真实通勤。用户尚未提供目的地、出行方式或生活偏好时，只问会改变筛选的关键缺口；不要擅自设定工作地或把普通商场当作每个人都需要的配套。

## 1. 户型与适住性

从该单元的现行挂牌、对应平面图或看房材料记录：独立卧室/卫生间数量、建筑与套内/使用面积的口径、客餐厅和厨房是否独立、楼层及电梯、采光面/朝向、阳台、储物、空调/供暖、家具与装修、可入住人数和交付状态。尤其要辨别“名义两居但一间无窗”“样板间而非目标单元”“同一小区不同户型”等情况；仅宣传标签或照片不足以确认实测面积、噪声、采光和功能。

结合用户的同住者、作息、在家办公、老人/儿童、无障碍、宠物和储物需求，写出**适合谁、哪里不合适、现场必须核实什么**。不是所有两居都适合三口之家；有电梯也不等于全程无台阶。若户型图/楼层/电梯资料缺失，明确未知，不靠小区平均户型推断。

## 2. 到常去地点的出行

为每个用户指出的目的地单独计算，不以行政区中心或小区中心代替出入口。先确认起终点精度、工作日/周末、期望到达或出发时间、每周次数、可用交通工具及是否接受换乘。用可用的地图/公交/铁路/道路工具查询，记录查询日期、路线链接或可复核的来源。若只有小区位置而没有楼栋入口，说明起点误差。

| 项目 | 至少说明 |
| --- | --- |
| 可行方式 | 步行、公交/地铁、骑行、驾车、打车等与用户实际可用方式；不机械列全部 |
| 路线 | 起终点、线路/换乘、步行接驳和候车；驾车另看停车和拥堵 |
| 时间 | **门到门**预计时间或区间，注明工作日早/晚高峰、查询时段；不要用车上时间冒充总通勤 |
| 金额 | 单程票价/估价、必要换乘/停车/过路费；按用户出行次数算往返及月度负担，列公式和假设 |
| 可靠性 | 班次、首末班、拥堵、雨天骑行、夜间回家等影响；未取得可靠数据则标未知 |

公共交通票价以当地交通或地图显示的对应路线为据；未显示就标未知，不按直线距离瞎算。打车动态价只能作为查询时估价。驾车费用若缺油耗、能源价格、停车费或过路费，不给虚假的“总成本”；可分列已知项和待确认项。比较多个候选时保持**同一目的地、时段和出行频率**。用户有多个固定目的地时逐一列出，不能只报其中最便利的一个；若要合并成月度出行费用，写每条路线的次数与算式。

多目的地费用可用 `python3 scripts/check_commutes.py <数据.json>` 复核；[输入和计算口径](commute-input.md)。它不会查询路线、验证票价或替用户选交通方式。

## 3. 生活配套与商圈

先按用户生活需求筛类别：日常买菜/超市、便利店、餐饮、药店、医疗、学校/托育、运动/公园、快递、银行、停车、商圈等。对每个**影响决策**的类别，给具名地点、类型、从房源的实际步行/骑行/乘车路线时间或距离、营业/服务时段（有证据时）及查询日期。商圈要说明名称、到达方式、典型功能，不只写“商业成熟”。

重点看可日常使用的设施是否在用户接受的时间范围内；距离很近但隔主干道、营业时间不匹配或需要预约，不能等同方便。医院/学校“附近”不代表可挂号、可入学；学位、入学资格及医疗可及性要按现行规则或实际服务再查。地图点位、评价和商户页面可能过期，应标明来源并在看房时核实关键设施。

不为凑数量罗列无关店铺。若某项生活需要没有找到可靠点位，写“未查实”及查询范围，不写“没有”；若发现噪声源、交通隔离或夜间活动，也作为实地核查问题，而非未经核实的负面结论。

## 简明比较

每套用同一张表展示：`户型/面积/适住人数与证据`、`各目的地×交通方式×门到门时间×单程及月费用`、`日常设施/商圈×到达时间`、`未知与现场核查`。先满足硬条件，再结合用户偏好说明取舍；不要把商业设施数量或地图评分加成一个武断的综合分。

## 执行替代，不停在地图空壳

继续读[具体工具、API命令、时刻表替代与商户路线](routing-guide.md)。有获准浏览器交互就用；否则用助手查步行路网/POI API、运营方时刻表和精确站对参考页。文本读取工具打不开方向链接，不等于所有HTTP来源被封。步行模型与有来源的时刻表组合可作为标注估计交付，不能冒充指定时刻行程；完整公交规划失败不应连具名商户与接驳估计都放弃。
