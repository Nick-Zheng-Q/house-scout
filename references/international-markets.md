# 按国家和司法辖区选择平台、检索词与费用字段

按**房源所在国家＋州/省/英国构成国/城市**选渠道，不按提问语言或用户国籍选。英文问东京房源仍查日本平台、使用 JPY；中文问悉尼则查澳大利亚平台、使用 AUD。国籍/居留身份会影响资格，不决定查哪个房源市场；只问与资格相关的事实，不索取身份证件。

只读下方对应地区，再读[成本比较与计算](cost-comparison.md)。中国大陆看[平台操作](platforms.md)。这里是起点，不是平台排名、完整覆盖或“彼此独立”的证明；不同平台可能转载同一套，或共用发布者，应回到发布者/运营方的目标单元页。

## 当地需要索取的费用，不写死统一费率

| 市场 | 月成本与初始现金核查 |
| --- | --- |
| 美国USD | 合同租金与优惠摊销租金分开；必要设施/服务/宠物费用、水电结算、停车及租客保险。申请/占房费、可退押金、预付租金分列，按当地规则查合法性及可退性。购房另核房产税、保险、HOA/公寓费、成交费和贷款报价。 |
| 英国GBP | 保留pw/pcm原值，核council tax责任/档位/减免及水电网。占房款、租赁押金、到期租金分开，先核是否抵扣/退还，避免重复计算。购房查产权类型、服务费及对应构成国购置税制度。 |
| 加拿大CAD | 水电暖气、停车储物、保险；押金、预付租金及收费规则按省核，不套美国押金假设。购房查公寓费、房产税、适用转让税和融资条件。 |
| 澳大利亚AUD | 周租换算；列水电等必要支付、bond与实际rent in advance；按州查规则和官方押金流程。购房按州/领地查转让税、适用买家身份限制、strata/council费与贷款。 |
| 新西兰NZD | 周租换算；查水电范围、bond与预付租金。查Tenancy Services及买家具体购房资格、地方rates/body corporate费、律师和融资费。 |
| 新加坡SGD | 租金、水电网、空调保养和实际合同必要收费；分列押金、中介费、印花税及到期日。HDB资格/批准/期限查HDB，私宅按适用URA规则；购置税和贷款限制查IRAS/贷款文件及买家情况。 |
| 中国香港HKD | 核租金是否包管理费、差饷/地租、水电和停车；押金、预租、中介费和适用厘印分列，不默认统一押金倍数或税率。 |
| 日本JPY | 家賃＋管理費/共益費及适用水电停车；初期费用逐项查敷金、礼金、仲介手数料、保証料、保险、换锁/清洁、按日租金、更新费及扣退条件。不能拿“几个月租金”替代真实账单。 |
| 德国EUR | 基础租金、服务/暖气预付款及包含范围，另付电网费与可能年终结算。Warmmiete已含的Nebenkosten不重复加。押金、厨房/家具购买分列。购房查实际购置税、公证、登记、中介报价与Hausgeld范围。 |
| 法国EUR | 基础租金与charges分开，核可结算的provision还是forfait、CC外水电保险；押金、中介/清单费和签约款逐项，适用限额查现行规则，不写统一金额。 |
| 荷兰EUR | 基础租金＋服务费及另付能源水网，核地方/水务税费责任。押金、家具、已证实费用分列；登记许可与租赁规则查市政府/现行正式来源，不凭广告认定。 |

## 交通、生活配套与正式核查来源

实际工具、公开HTTP替代、精确时刻/路线检索和商户定位器见[路线操作指引](routing-guide.md)，不要停在下表主页。


用[Google Maps](https://www.google.com/maps)或当地可用地图查**出入口到出入口**路线及具名商户，操作见[enrich步骤](enrichment-guide.md)。设当地工作日/到达时刻，返程独立查；再查实际运营方票价/月票/换乘条件。站到站路线缺少两端步行接驳。

| 市场 | 交通与正式核查路径 |
| --- | --- |
| 美国 | 搜实际城市的`[city] official transit trip planner fare`，不是套全国票价。租赁规则查州/市住房部门；购房融资看[CFPB购房资源](https://www.consumerfinance.gov/owning-a-home/)，税/产权查对应县/州及贷款文件。 |
| 英国 | 伦敦看[TfL路线](https://tfl.gov.uk/plan-a-journey/)及票价，其他城市查本地公交/铁路；[GOV.UK私人租赁](https://www.gov.uk/private-renting)作为偏英格兰入口，其他构成国查其政府，不套英格兰规则；council tax查实际地方政府。 |
| 加拿大 | 查实际市/省运营方，如多伦多TTC/GO、温哥华TransLink，不跨城套月票。租赁查对应省机构，如Ontario Landlord and Tenant Board。 |
| 澳大利亚 | 悉尼/NSW看[Transport for NSW](https://transportnsw.info/)，其他州查自身运营方；[NSW租赁指引](https://www.nsw.gov.au/housing-and-construction/renting-a-place-to-live)只是该州例子，购房税查实际州税务机构。 |
| 新西兰 | 奥克兰看[Auckland Transport](https://at.govt.nz/)，其他城市查本地运营方；[Tenancy Services](https://www.tenancy.govt.nz/)查租赁，地方政府/购房资格官方来源查购买事项。 |
| 新加坡 | [OneMap](https://www.onemap.gov.sg/)查地点/路线；[SimplyGo](https://www.simplygo.com.sg/)查票价、换乘/月票；[HDB](https://www.hdb.gov.sg/)→租/购，私宅/税/中介问题查当前URA、IRAS、CEA。 |
| 中国香港 | [MTR](https://www.mtr.com.hk/en/customer/main/index.html)及实际巴士/渡轮运营方，核支付方式/换乘；相关租赁/税/产权分别查差饷物业估价署、税务局、土地注册处。 |
| 日本 | 查实际JR/私铁/地铁/巴士及对应线路通勤定期券，核高峰换乘和末班；租约指引查MLIT/地方政府，购买产权/外文合同需当地合格专业人员核实。 |
| 德国 | [DB](https://www.bahn.de/)＋实际交通联合机构（如柏林VBB）；查月票覆盖哪些服务而非只看广告价格。法律/税看政府正式法条入口、城市部门及所在州税务局。 |
| 法国 | 巴黎区域看[RATP](https://www.ratp.fr/)及区域票价机构，其他城市查实际运营方；[Service-Public住房](https://www.service-public.gouv.fr/particuliers/vosdroits/N19808)查租购事项，购置费查税务机关/对应公证报价。 |
| 荷兰 | [9292](https://9292.nl/en/)及对应运营方/NS条件，核订阅覆盖/自行车接驳；[Government.nl租赁](https://www.government.nl/themes/building-and-housing/housing/rented-housing)、市政府和相关租赁机构查规则。 |

这些是入口，不表示已取得任何具体路线、票价或法律结论。2026-10-19 静态访问Transport for NSW与Tenancy Services超时，OneMap没有可读正文，故该会话内实际可用性**未核实**，应按访问失败处理，不能称路线调研完成。

配套用英文和当地词分别搜：日本`スーパー / 薬局 / 商店街`；德国`Supermarkt / Apotheke / Einkaufszentrum`；法国`supermarché / pharmacie / centre commercial`；荷兰`supermarkt / apotheek / winkelcentrum`；香港`街市 / 藥房 / 商場`；新加坡`supermarket / wet market / pharmacy / mall`。打开具名商户再查路线，不能把搜索半径命中当作方便到达。

## 表外市场

不硬套美英模板。搜`[city country] apartment rent buy`及当地语言等价词，核两个当地发布渠道及住房/税务/交通正式来源，再固定货币、报价周期、房间/面积定义及必要费用字段，之后才比较。公开说明哪些来源/假设未核实；本指南不是全球法律覆盖。
