# 统一成本口径：报价周期、初始现金、交通和购买情景

选定[市场](international-markets.md)或[中国大陆](platforms.md)后使用。每笔保留币种代码、原金额/周期、包含项目、可退性、到期日、来源和日期。当地费用类别是待核问题，不是可直接套用的金额。

## 1. 周期换算不改变实际付款安排

用于预算比较的**按52周年化**约定：

| 原报价周期 | 月度等价 |
| --- | --- |
| week / pw 周 | 金额×52÷12 |
| fortnight 每两周 | 金额×26÷12 |
| month / pcm 月 | 原金额 |
| quarter 季 | 金额×4÷12 |
| year 年 | 金额÷12 |

这是比较约定，不是法律上的按日计租。合同可能按日历结算，选定区间可能出现53次周付款，也可能有专门首月分摊/续租价格。不得据此反推某个签约日实付。日报价/不规则报价必须用实际日期和合同规则，不能默认每月30天。

`python3 scripts/normalize_costs.py input.json --pretty` 按上表换算已录入的经常费用；缺周期、负数、非有限数、混币种报错，null保持未知。它不查收费、不判合法性、不换汇、不算签约现金。输入示例：

```json
{"currency":"AUD","costs":[
  {"name":"rent","amount":650,"period":"week"},
  {"name":"internet","amount":60,"period":"month"},
  {"name":"electricity","amount":null,"period":"quarter"}
]}
```

租金月等价AUD2,816.67，已知小计AUD2,876.67；电费和必要费用是否完整仍未知。换算后的经常费用填入[租赁脚本输入](check-input.md)，不能因金额已算出而把完整性设为true。换算脚本用Decimal，先累加未舍入值再按两位小数展示；保留原精度，实际付款按合同/当地货币结算规则舍入。

优惠另列合同正常实付和**相同计划住期**的有效租金情景：`(住期内实际应付租金之和－已确认租金抵扣)÷居住月数`。已在实付中抵扣的不再扣一次；12个月免一月的条件未允许6个月租期时，不套给6个月住期。押金与预付租金不是优惠。

## 2. 成本和资金占用分开

- 必要住房月费＝换算后租金＋尚未包含的必要经常费用。德国Warmmiete、法国CC、全包租金先核范围，已包的项目不重复加；水电未知保持未知或给有来源区间。
- 不可退初期费用＋可退押金（**不含预付租金**）表示费用和被占用现金，不是月租。
- 签约/入住现金＝截至该日实际到期的预租、押金、费用/税等，减去已确认用于抵扣对应项目的已付款。占房款抵租金后不能再加一次；后期账单另列。
- 可选住期成本情景＝该住期经常支出＋不可退一次性费。全额可退押金不当消费，另列占用及有依据的可能扣款。不能把初期费摊到月后隐藏真实签约现金。

**虚构澳大利亚例子：**AUD650/周、网费60/月、电费未知；报价明确押金2,600＋预付两周租金1,300在签约日到期。住房已知月等价2,876.67；只有完整到期清单已核清，才能说签约现金3,900。押金倍数是模拟输入，**不是某州法律标准**。若住房月预算3,000，仍因电费未知而不能判总成本未超。

## 3. 通勤和家庭月度负担

门到门分钟＝入口步行/接驳＋候车＋乘坐＋换乘＋终点接驳，含用户需要的台阶/电梯环节。地图总时间已含这些部分时，不再加一次步行。按当地工作日、期望到达时刻和返程出发时刻分别查，直线距离不是时间。

每目的地按次支付月费情景＝实际往返次数×(去程费＋返程费)＋必要附加费。换乘一体票价不能把每段单独票价机械相加。比较月票/封顶前核当前路线/区域/方式/时段适用性；一张覆盖多个目的地的月票只计一次。多人出行要核乘客人数和适用票种，不给每人默认成人票。

[出行脚本](commute-input.md)每目的地录一种实际计划方式。多目的地共用月票时，已确认覆盖行程的增量票价填0，月票放一条路线的`extra_monthly_cost`并解释分配；未覆盖行程照录票价。不能每条重复计月票或把备选方式相加；脚本不会自动选月票或应用封顶。没有返程票价则null。

家庭月度负担＝同币种、同月份、同家庭人数/行程口径的必要住房＋交通。任何一边不完整，结果只是已知小计，不是总负担可承受。跨币种保留原币，换算情景另列有日期汇率来源、方向、手续费及舍入；不同国家的“$”不可直接相加。

## 4. 买房：自备现金与融资月费分开

交易税/费用用当前适用于房源和买家的正式规则/计算器，不能套全球统一百分比。美国[CFPB购房资源](https://www.consumerfinance.gov/owning-a-home/)提供贷款估算和成交文件指引，其他市场查实际贷款方及主管机关。

- 购价自备款＝议定价格－实际可用融资。购置所需现金还包括适用税、公证/律师/登记/中介费、维修和交割调整。已抵购价订金本来就是自备款的一部分，不再额外加成购价。
- 交割剩余现金＝已核实的剩余价款/费用－交割融资－尚应抵扣的已付款；前期订金和后期费用另列，每笔抵扣只一次。
- 固定月利率`r`、本金`L`、剩余`n`个月的等额本息贷款：`月供=L*r/(1-(1+r)^(-n))`；`r=0`时为`L/n`。必须核**实际月利率约定**；只有合同采用该口径时才用年名义利率÷12。有效年利率、加拿大常见名义半年复利、重定价/只付息/尾款贷款用各自约定，APR不自动等于还款计息率。
- 所有权月现金流还要加房产税、保险、HOA/strata/管理/服务费、维修假设、水电；escrow或其他合计已含的不重复计。这仍不是完整租购经济比较，还存在本金形成权益、退出费及资产价格风险。

租赁与周期换算脚本**不计算购房资格、交易税或贷款批准**。价格、融资、到期日未核实前都标情景，不判预算已过关。
