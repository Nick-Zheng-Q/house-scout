# 搜索与发现方法

用于从零找房；审查用户材料时只补查缺口。目标不是穷尽全城，而是在用户能接受的每个区域找到可比较的**具体单元和现行条件**，并让未查实处可追溯。

实际执行前先读[具体平台、站内筛选与搜索词](platforms.md)；本页补充跨平台的对象对齐、来源限制和停止标准。

## 搜索对象与词

由城市、区域、租/购、户型、预算、入住或交付时间生成词，如 `[区域] [整租/合租/长租公寓/二手房/新房] [户型] [价格段]`。同时可从用户常去地点反向找：先用地图看可接受通勤时间内的线路/站点与片区，再在这些片区检索具体房源；**通勤圈只是发现范围，不证明某套的门到门时间**。硬条件中少见的词（宠物、无障碍、短租、车位）可用于第二轮核查；初搜全部附加会漏掉未写标签但可能符合的房源。用户提到多个区域时逐区查，不因先找到一个合适结果就停止其他区域。搜索当地实际存在的保障或特殊供给时，另查现行资格和申请窗口，不默认人人可用。

## 去哪里找

按当地实际供给选择渠道，至少覆盖适合该交易方式的不同发布主体，不依赖单个平台排序：

| 渠道 | 找什么 | 下一步 |
| --- | --- | --- |
| 当地主流房源平台和经纪机构的具体挂牌页 | 房源编号、单元线索、户型图、报价、发布日 | 去重，核经纪身份及现行价格/空置；不把平台标签当书面条款 |
| 业主直租/直售、长租公寓运营方、开发商项目或官方销售页 | 直接供给和特定房型/单元 | 核出租/出售权限、目标单元、可交付日及全部费用；直租不一定有官网 |
| 当地住房保障、人才住房、公共租赁或交易服务的正式入口（仅相关时） | 可能的低价/资格型供给和申请窗口 | 核申请人资格、配额、实际单元、期限及限制，未获批不作基础价格 |
| 地图及交通服务 | 找通勤可达片区、楼栋出入口、站点和生活设施 | 回到具体房源；对候选逐一查询路线、费用和设施，不以地图点位证明房源可用 |

用户已有链接、熟人推荐和社区帖子可加为线索。搜索时记录渠道、检索词、筛选条件和查阅日期；若只搜到一个平台或某类供给缺失，交代覆盖局限，不冒称“全城最优”。

## 来源与追查

| 来源 | 可用于 | 不能单独证明 |
| --- | --- | --- |
| 平台/经纪挂牌 | 发现编号、位置、图片、报价和联系人 | 当前可用、授权、完整费用、房屋真实现状 |
| 业主/运营方/开发商页面或书面回复 | 对齐该主体所给现行条件 | 产权无瑕疵、现场质量、合同最终内容 |
| 地图/交通服务 | 估算路线、周边设施 | 高峰通勤、噪声、安全、学位资格 |
| 当地正式登记、政策、交易渠道 | 核查其公开范围内的规则和记录 | 未公开的私下约定或房屋物理缺陷 |

沿“线索 → 房源编号/具体单元 → 发布者及其权限 → 对应报价/日期/状态 → 公开联系入口”追查。房东直租未必有官网，不能因为没有企业网站就排除；应明确只能靠后续授权文件和现场核验。多个中介发布同一套时合并为一套，但各自报价、面积或费用冲突须保留，不能挑最低价当确定价。相同小区不同单元不合并。图文或视频无法确定属于该单元时标未知。

## 先粗筛，再精查

先排除有证据表明违反硬条件的单元；其余核查能改变排序的少数事项：实际可用日期、月/总价口径、必要费用、合同期限、真实房型、发布权限、不可现场推断的政策资格。对留下的候选执行[户型、出行及生活配套核查](enrichment-guide.md)：户型图/楼层/面积须属于该单元；各常去地点按用户可用交通方式查门到门时间和费用；周边设施需具名、标实际到达时间。学校、落户、购房资格及贷款不能从地图或房源标签直接推断。

完整地址和房号若涉及居住者隐私，不在公开答复中不必要地展开；可用公开编号和足够区分单元的字段。仅小区介绍、历史成交、下架页、无法对应到单元的样板间或未证实申请资格的项目，列待追查线索，不计可直接联系候选。

## 何时停止

逐区域记录查过的渠道、代表性检索词和仍未查实的线索。每个保留候选应有具体单元、当期条件的来源、公开联系入口、户型适配、通勤和生活配套核查，以及明确的未知和下一步问题。对明显更便宜、位置更好或有资格门槛的供给，至少追到现行入口或说明追不到。若后续搜索只重复相同房源/旧资料，可停止并坦白缺口；没有找到不代表不存在。报价、状态、空置和规则在行动前须再次确认。
